# Описание проекта в репозитория `golang/go`

## В папке `.github` находятся шаблоны текстов которые выводятся пользователям и разработчикам 
Файлы папке `ISSUE_TEMPLATE` это файлы шаблонов создания новых задач `Issues` для того чтобы стандартизоваь сообщения от пользователей и разработчиков

aleksey@aleksey:~/go_src/src$ GOROOT=$(pwd)/.. go test cmd/api``

Сборка выполняется командой `./make.bash` и не требует дополнительных внешних зависимостей. Для сборки проекта достаточно наличие установленного `go`. Всё включено уже в проект. Сборка проекта происходит невероятно быстро.
