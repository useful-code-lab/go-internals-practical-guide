# Описание проекта в репозитория `golang/go`

## В папке `.github` находятся шаблоны текстов которые выводятся пользователям и разработчикам 
Файлы папке `ISSUE_TEMPLATE` это файлы шаблонов создания новых задач `Issues` для того чтобы стандартизоваь сообщения от пользователей и разработчиков

## В папке ``api`` находятся файлы для фиксации сделанных изменений в проекте. Туда информация пишется после запуска тестов
$ cd ~/go_src/src  # (или где у вас лежат исходники Go)
aleksey@aleksey:~/go_src/src$ GOROOT=$(pwd)/.. go test cmd/api``
``
Нужно уточнить что тестирование происходит строко на предыщих версиях `go`. Собирать же можно на любых версиях.
Сборка выполняется командой `./make.bash` и не требует дополнительных внешних зависимостей. Для сборки проекта достаточно наличие установленного `go`. Всё включено уже в проект. Сборка проекта происходит невероятно быстро. Собранные файлы лежат в директории `bin`

## В папке `doc` находится документация для разрабочика
Например, `asm.html` - это Go-ассемблер, дополнительный слой абстракции между ассемблером. Это нужно для аппаратной совместимости Golang на разных платформах `linux`, `windows`, `arm` и прочее. Для адаптации на новых платформах достаточно доработать линкование папке `cmd/link`. В этой папке находится файл `main.go` для запуска процесса линкования. Сами адапатации на платформы описаны в папке `src/cmd/link/internal`. Универсальный слой похожий на ассемблер создает скрипт  `src/cmd/asm/internal/lex/lex.go` и `asm.go`.

# Конвеер превращения `go`-кода в машинный код
1. Текст `Go`
2. Токены - нарезка на заничмые смиволы
3. Постройка дерева `AST`
4. Проход по дереву и проверка логики программы
5. SSA(промежуточное предстваление)
6. Машинный код

## В папке `lib` находятся вспомогательные файлы с данными для разработки `go` совмесно с другими сервисами

## `misc` - тут просто файлы полезные сообществу `golang` но не относящиеся к `golang` непосредственно

## `pkg` - тут хранятся промежуточные файлы компиляции. Но это просто часть кешей. Другая часть кешей находится `/home/aleksey/.cache/go-build/`
